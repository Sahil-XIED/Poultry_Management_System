# 🐓 FarmGuard – Poultry Intelligence System

FarmGuard is a real–farm–oriented Poultry Management System designed to help farmers track **mortality, diseases, vaccination, feed consumption, egg production, and profit & loss** in one intelligent dashboard.

This project is built using **HTML, CSS, and JavaScript (frontend simulation)** with a ready **MySQL schema** for backend integration.

---

## 🌟 Features

### 🧠 Real Farm Problem Tracking
- Mortality logging with severity alerts  
- Disease outbreak register  
- Vaccination schedule & overdue warnings  
- Feed & water consumption monitoring  
- Egg production and lay-rate analysis  
- Profit & Loss calculator  

### 📊 Dashboard Intelligence
- Live bird count  
- Mortality percentage  
- Daily egg production  
- Feed consumption vs target  
- Financial overview  

### 🧾 Reports
- Export CSV for:
  - Mortality logs  
  - Vaccination history  
  - Egg collection  
  - Flock registry  

### 🔔 Alerts System
- Critical disease warnings  
- Overdue vaccine alerts  
- Low feed stock notification  
- High mortality detection  

---

## 🛠 Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Database:** MySQL (schema included)  
- **UI Design:** Custom modern dark theme  
- **Data Storage (demo):** Local JS state (replaceable with backend)
